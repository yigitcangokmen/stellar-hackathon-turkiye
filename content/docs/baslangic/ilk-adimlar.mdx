# İlk Adımlar

Bu sayfada cüzdan kuracak, testnet XLM alacak ve ilk işlemini yapacaksın.

## 1. Freighter Cüzdan Kurulumu

[Freighter](https://www.freighter.app/), Stellar'ın resmi tarayıcı cüzdan uzantısıdır.

1. **Chrome/Brave** kullanıyorsan: Chrome Web Store'dan "Freighter" uzantısını kur
2. Yeni bir cüzdan oluştur
3. **Recovery phrase'ini** güvenli bir yere yaz (kağıda, şifre yöneticisine)
4. Ayarlardan ağı **Testnet**'e çevir

> Testnet'e geçmeyi unutma! Varsayılan ağ Mainnet'tir.

## 2. Testnet XLM Al (Friendbot)

Testnet'te işlem yapabilmek için XLM'e ihtiyacın var. Friendbot bedava verir:

### Tarayıcıdan

[Stellar Lab - Fund Account](https://lab.stellar.org/account/fund) adresine git, Freighter'daki public key'ini yapıştır, "Fund" tıkla.

### Koddan

```js
// JavaScript
const response = await fetch(
  `https://friendbot.stellar.org?addr=${publicKey}`
);
const result = await response.json();
console.log('Fonlandi:', result);
```

```python
# Python
import requests

response = requests.get(
    f"https://friendbot.stellar.org?addr={public_key}"
)
print("Fonlandi:", response.json())
```

## 3. Stellar Lab ile İlk İşlem

[Stellar Laboratory](https://lab.stellar.org) Stellar'ın resmi test arayüzüdür. Buradan işlem oluşturabilir, imzalayabilir ve gönderebilirsin.

1. Lab'a git, **Testnet** seçili olduğundan emin ol
2. "Build Transaction" bölümüne geç
3. Source account olarak kendi public key'ini gir
4. Operation olarak **Payment** seç
5. Hedef adres, asset (native XLM) ve miktar gir
6. "Sign in Freighter" ile imzala
7. "Submit Transaction" ile gönder

## 4. Explorer'da Kontrol Et

İşlemin gerçekleştiğini doğrulamak için:

- [Stellar Expert (Testnet)](https://stellar.expert/explorer/testnet) adresine git
- Public key'ini veya transaction hash'ini ara
- İşlem detaylarını incele

## 5. USDC Trustline Aç

Anchor entegrasyonu için USDC'ye ihtiyacın olacak. Önce trustline açman gerekiyor:

```js
// JavaScript
import {
  Keypair,
  Server,
  TransactionBuilder,
  Networks,
  Operation,
  Asset,
} from '@stellar/stellar-sdk';

const server = new Server('https://horizon-testnet.stellar.org');

// Testnet USDC issuer (Circle)
const USDC = new Asset(
  'USDC',
  'GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5'
);

const account = await server.loadAccount(publicKey);
const tx = new TransactionBuilder(account, {
  fee: '100',
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(Operation.changeTrust({ asset: USDC }))
  .setTimeout(30)
  .build();

tx.sign(keypair);
await server.submitTransaction(tx);
console.log('USDC trustline acildi!');
```

## 6. Testnet USDC Al
